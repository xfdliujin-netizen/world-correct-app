# 错字本

纯静态 WebApp，可直接部署到 GitHub Pages，无需后端或 npm 构建。

## 多端同步

1. 各设备通过 HTTPS 打开网页，在「云同步」填写同一个 GitHub Token（Gists 读写权限），连接同一份 Gist，开启自动同步。
2. 编辑后先写入本机，停止输入 1.5 秒后上传 Gist。上传成功后经 MQTT 发布 `{type:"updated",at:时间戳}`，不广播字库、Token 或 API Key。
3. 其他设备收到通知即拉取 Gist；首次订阅、断线重连、恢复网络和回到前台都会补拉。没有定时短轮询。网络正常时通常数秒完成，GitHub API 和公共 Broker 的延迟、配额、可用性会影响实际速度。
4. 默认通知服务：`wss://broker.emqx.io:8084/mqtt`，MQTT.js 5.10.4 从 jsDelivr 按需加载。频道由同一 Gist ID 和 Token 的 SHA-256 摘要生成；不同 Token 不会加入同一频道。
5. 公共 Broker 不提供私有频道访问控制，摘要频道也可能被通配符订阅者观察。通知仅含更新时间；真实字库仍由 GitHub Token 授权读取。频道名不是安全边界。
6. 本机未上传而云端更新时提示选择；整库快照不支持多人同时修改的自动逐字合并。公共 Broker 不可用时，回到前台仍可通过 Gist 对齐。

## 填词游戏

独立「填词游戏」Tab。配置自己的 DeepSeek API Key，选取字库生字，生成 3 个词语、3 个成语、3 个佳句。每项挖去目标生字的全部出现位置，支持键盘输入或手写识别后选择确认。答对或跳过后展示完整内容，点「读一读，下一题」继续；完成后回顾全部素材。

提示词要求素材包含目标字，佳句优美、积极、具有画面感与科普或文学色彩，15～30 个汉字，适合硬笔练习。客户端验证数量、去重、包含关系和长度；不足会重试，仍不合格则提示换字，避免为了数量生造成语。AI 内容仍建议家长陪同阅读。生成题目缓存在本机。

API Key 仅存在当前浏览器本地存储，并直连 DeepSeek，不进入 Gist 和 MQTT。共享设备请在 AI 设置中清除 Key。

## 验证

运行 `node verify-project.cjs` 和 `node verify-sync.cjs`。`browser-check.cjs` 使用 Playwright 验证 iPhone、iPad、分屏尺寸的填空与按钮交互。联网服务需要部署后用两个真实设备验证，不能将本地模拟结果视为公网联通保证。
